# Iniyaraja I. — Developer Portfolio

A responsive single-page React portfolio built with Vite.

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Production build

Run `npm run build`. The deployable site will be generated in `dist/`.

## Deploy

You can deploy the `dist/` folder to Netlify, Vercel, GitHub Pages (with suitable Vite base configuration), or any static hosting provider.

## Included assets

- `public/assets/profile.png` — supplied profile photo
- `public/assets/Iniyaraja-Resume.pdf` — supplied resume PDF

The contact form uses a `mailto:` link and opens the visitor's default email application. To receive messages directly on a website, connect a form backend or form service before production deployment.

## Update content

Edit the arrays and sections in `src/main.jsx`. Replace the resume file in `public/assets/` when you have an updated portfolio-aligned PDF.
